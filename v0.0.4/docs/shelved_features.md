# future features

## feature list

> **1.** Add a single-screen "watch" mode (live updating table every N seconds) using Rich's live rendering, still keeping it aligned with the purpose (visibility, not fluff).
> **2.** Add a "trim fat" mode that automatically terminates processes based on a configurable threshold (e.g., CPU% or RAM usage). This should be a confirmable action, not an auto-fire.
> **3.** Add a "baseline" mode that saves the current process list to a file, and a "diff" mode that compares the current process list to a saved baseline and shows only the differences.
> **4.** add a **single-screen “watch” mode** (live updating table every N seconds) using Rich’s live rendering, still keeping it aligned with the purpose (visibility, not fluff).
