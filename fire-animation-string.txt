# ══════════════════════════════════════════════════════════════
#  FIRE ANIMATION — peepBeefy Banner
#
#  8-frame sway cycle. Forward lean (01→05), reverse lean (B-slides).
#  Lines 1-5 sway with decreasing amplitude + counter-sway on Line5.
#  Lines 6-8 are anchored (text body = fuel source, doesn't move).
#
# ══════════════════════════════════════════════════════════════
#  FIRE PALETTE  (low-bit — classic demoscene fire gradient)
#
#  The fire rises from the text. Tips are sparse and bright.
#  Core is dense and hot. Text glows white-hot at the source.
#
#   Line1  TIPS      #FFD700  bright yellow      sparse, flickering tips
#   Line2  UPPER     #FF8C00  dark orange        gathering, visible heat
#   Line3  BODY      #FF4500  orange-red         dense flame core
#   Line4  LOWER     #CC2200  dark red-orange    heavy base of flame
#   Line5  EMBER     #8B1A00  deep ember red     where fire meets text
#   Line6  TEXT-HOT  #FFFFFF  bold white         white-hot letterforms
#   Line7  TEXT-MID  #CCCCCC  white              cooling glow
#   Line8  TEXT-DIM  #999999  dim gray           base, furthest from flame
#
#  ANSI FALLBACK (strict 16-color terminals):
#   Line1  bright_yellow   \e[93m
#   Line2  yellow          \e[33m
#   Line3  bright_red      \e[91m    (reads orange on most terminals)
#   Line4  red             \e[31m
#   Line5  red dim         \e[2;31m
#   Line6  bold white      \e[1;37m
#   Line7  white           \e[37m
#   Line8  dim             \e[2m
#
# ══════════════════════════════════════════════════════════════
#  ANIMATION CYCLE
#
#  FORWARD:   Slide_01 → 02 → 03 → 04 → 05 (return to default)
#  REVERSE:   Slide_01 → 02-b → 03-b → 04-b → 05-b (return to default)
#
#  Full loop: 01 → 02 → 03 → 04 → 05 → 02-b → 03-b → 04-b → 05-b → repeat
#
#  Each offset is DELTA from previous frame.
#  Only Lines 1-5 sway. Lines 6-8 are anchored.
# ══════════════════════════════════════════════════════════════
